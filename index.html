How to post to the map

1
Run a Logos node

Follow the setup guide and run a local node connected to the Logos testnet.

github.com/logos-co/nomos-node →

2
Geo-link your node (optional)

To anchor your messages to your real map location, add your username and public IP to geo_hints.json in this repo:

{ "your_username": "1.2.3.4" }

Open a PR or ping us and we'll add it.

3
Post to the map

Send a zone-board message on your node that contains #live. The scanner picks it up within ~30 seconds of block finalization and it appears as a pinned bubble on the map.

channel: logos:yolo:<your_username> message: "Running well today #live"
