How to post to the map

      
    

    

      

        
1

        

          
Run a Logos node

          
Follow the setup guide and run a local node connected to the Logos testnet.

          
github.com/logos-co/nomos-node →

        

      

      

      

        
2

        

          
Announce your location (optional)

          
Post a message with #geo lat,lon once. The scanner anchors your future messages to that spot on the map.

          #geo 51.5074,-0.1278
        

      

      

      

        
3

        

          
Post to the map

          
Send a zone-board message containing #live. It appears as a pinned bubble on the map within ~30 seconds of block finalization.

          channel:  logos:yolo:<your_username>
message:  "Running well today #live"
